# 🚀 Among Us - JavaScript

Um jogo interativo inspirado no clássico **Among Us**, desenvolvido utilizando tecnologias web fundamentais (HTML5, CSS3 e JavaScript).

## 📌 Sobre o Projeto

Este projeto consiste em uma recriação/simulação do jogo Among Us rodando diretamente no navegador. O objetivo é demonstrar conceitos de desenvolvimento web frontend, manipulação de DOM, lógica de jogos e estilização em CSS.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura da página e elementos do jogo.
- **CSS3:** Estilização, layout responsivo e animações.
- **JavaScript (ES6+):** Lógica do jogo, controle de eventos e movimentação.

---

## 🎮 Como Jogar / Funcionalidades

- **Movimentação:** Utilize as teclas direcionais do teclado ou as teclas `W`, `A`, `S`, `D` para mover o personagem.
- **Interação:** Interaja com os objetos do mapa para realizar tarefas ou acionar ações.
